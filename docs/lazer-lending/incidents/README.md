# Incident postmortems

File naming: `YYYY-MM-DD-<short-slug>.md` (e.g., `2026-06-15-mailbox-bulk-pause.md`).

Each incident postmortem must include:
- **Summary**: 1–2 sentences (what happened, when detected, when resolved)
- **Timeline**: timestamped events from detection to resolution
- **Root cause**: technical + process root causes
- **Resolution**: what was done; was it the OPS-RUNBOOK procedure or improvised?
- **Action items**: concrete follow-ups with owners + due dates
- **OPS-RUNBOOK update needed?**: yes/no — if yes, what does the runbook need to add or change?

See `docs/lazer-lending/OPS-RUNBOOK.md` for the 10 baseline incident-response procedures.
